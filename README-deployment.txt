S Vinish Ranganath — Portfolio Website

FILES
- index.html: the complete portfolio website, including styling and scripts.

DEPLOY TO GITHUB PAGES
1. Create a GitHub repository named vinish-portfolio.
2. Upload index.html to the repository root and commit it.
3. Open Settings > Pages.
4. Choose "Deploy from a branch", select branch "main" and folder "/ (root)", then Save.
5. Wait for GitHub Pages to show the published URL.

DEPLOY TO NETLIFY
Option A — connect GitHub:
1. Upload index.html to a GitHub repository.
2. In Netlify, choose Add new project / Import an existing project and select the GitHub repository.
3. Leave the build command blank and set the publish directory to "." (repository root).
4. Deploy the site.

Option B — manual deploy:
1. Put index.html in a folder.
2. Open https://app.netlify.com/drop and drag that folder into the page.

NOTES
- This is a static HTML site; no build command or package installation is needed.
- Review employment dates, contact information, and other personal details before making the site public.
- The résumé section has a Print / Save résumé as PDF option; a separate résumé PDF is not included.
